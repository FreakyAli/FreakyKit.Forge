# Migrating from Mapster to Forge

A pattern-by-pattern migration guide for teams moving from Mapster to Forge. Mapster supports both reflection-based and code-generation approaches — this guide covers both.

> **Why migrate?** Mapster's reflection mode has runtime overhead; its code-generation mode (Mapster.Tool) generates code but still requires a runtime dependency. Forge is pure compile-time: zero runtime dependencies, zero reflection, and 85 build-time diagnostics that catch mistakes before you run.

## 1. Setup & Registration

### Mapster

Mapster uses extension methods with global or per-type configuration:

```csharp
// Global configuration
TypeAdapterConfig.GlobalSettings.Default.PreserveReference(true);

// Per-type configuration
TypeAdapterConfig<Person, PersonDto>.NewConfig()
    .Map(dest => dest.DisplayName, src => src.FullName);

// Or via DI
services.AddSingleton(TypeAdapterConfig.GlobalSettings);
services.AddScoped<IMapper, ServiceMapper>();
```

### Forge

No runtime configuration, no DI:

```xml
<PackageReference Include="FreakyKit.Forge.Generator" Version="1.5.0" />
<PackageReference Include="FreakyKit.Forge.Analyzers" Version="1.5.0" />
```

```csharp
using FreakyKit.Forge;

[Forge]
public static partial class PersonForges
{
    public static partial PersonDto ToDto(Person source);
}
```

**Key difference:** Mapster's configuration is runtime (fluent API or attributes). Forge's configuration is compile-time (attributes on types + method declarations).

## 2. Basic Property Mapping

### Mapster

```csharp
// Extension method (reflection-based)
var dto = person.Adapt<PersonDto>();

// Or with config
TypeAdapterConfig<Person, PersonDto>.NewConfig();
var dto = person.Adapt<PersonDto>();
```

### Forge

```csharp
[Forge]
public static partial class PersonForges
{
    public static partial PersonDto ToDto(Person source);
}

var dto = PersonForges.ToDto(person);
var dto2 = person.ToDto(); // extension method (generated by default)
```

## 3. Custom Member Mapping

### Mapster

```csharp
TypeAdapterConfig<Person, PersonDto>.NewConfig()
    .Map(dest => dest.DisplayName, src => src.FullName);
```

Or with attributes:

```csharp
public class PersonDto
{
    [AdaptMember(nameof(Person.FullName))]
    public string DisplayName { get; set; } = "";
}
```

### Forge

```csharp
public class PersonDto
{
    [ForgeMap("FullName")]
    public string DisplayName { get; set; } = "";
}

[Forge]
public static partial class PersonForges
{
    public static partial PersonDto ToDto(Person source);
}
// Generates: __result.DisplayName = source.FullName;
```

## 4. Ignoring Members

### Mapster

```csharp
TypeAdapterConfig<Person, PersonDto>.NewConfig()
    .Ignore(dest => dest.InternalId);

// Or with attribute
public class PersonDto
{
    [AdaptIgnore]
    public string InternalId { get; set; } = "";
}
```

### Forge

```csharp
public class PersonDto
{
    [ForgeIgnore]
    public string InternalId { get; set; } = "";
}
```

**Forge's advantage:** Side-specific exclusion — `[ForgeIgnore(Side = ForgeIgnoreSide.Source)]` excludes a member from the source side only, without affecting its role as a destination member.

## 5. Nested Object Mapping

### Mapster

```csharp
// Mapster handles nested mapping automatically
TypeAdapterConfig<Person, PersonDto>.NewConfig();
TypeAdapterConfig<Address, AddressDto>.NewConfig();
var dto = person.Adapt<PersonDto>(); // Address → AddressDto discovered at runtime
```

### Forge

```csharp
[Forge]
public static partial class PersonForges
{
    public static partial AddressDto ToAddressDto(Address source);

    [ForgeMethod(AllowNestedForging = true)]
    public static partial PersonDto ToDto(Person source);
}
```

**Key difference:** Forge requires `AllowNestedForging = true` — explicit opt-in prevents accidental deep traversal.

## 6. Collection Mapping

### Mapster

```csharp
var dtos = orders.Adapt<List<OrderDto>>();
```

### Forge

```csharp
[Forge]
public static partial class OrderForges
{
    public static partial OrderDto ToDto(Order source);
    public static partial List<OrderDto>? ToDtos(List<Order>? source);
}

var dtos = OrderForges.ToDtos(orders);
```

Both handle the same collection types. Collection properties are mapped automatically with `AllowNestedForging = true`.

## 7. Constructor Mapping

### Mapster

```csharp
TypeAdapterConfig<Source, Dest>.NewConfig()
    .MapToConstructor(true);
```

### Forge

```csharp
// Automatic — Forge selects the best constructor by default
[Forge]
public static partial class MyForges
{
    public static partial Dest ToDto(Source source);
}

// Use [ForgeMap] on constructor parameters for name mismatches
public class Dest
{
    public Dest([ForgeMap("FullName")] string name) { Name = name; }
    public string Name { get; }
}
```

## 8. Enum Mapping

### Mapster

```csharp
// Mapster maps enums by value (cast) by default
TypeAdapterConfig<Source, Dest>.NewConfig()
    .Map(dest => dest.Status, src => src.Status.ToString());  // enum to string
```

### Forge

```csharp
// Cast (default — same as Mapster)
public static partial Dest ToDto(Source source);
// Generates: __result.Status = (DestStatus)source.Status;

// By name
[ForgeMethod(MappingStrategy = ForgeMapping.ByName)]
public static partial Dest ToDtoSafe(Source source);

// Enum ↔ string is automatic:
// Enum → string: source.Status.ToString()
// String → enum: Enum.Parse<T>(source.Status)
// String → enum with fallback: [ForgeMap("Status", DefaultValue = Status.Unknown)]
```

## 9. Flattening

### Mapster

```csharp
// Mapster flattens by convention (same as AutoMapper)
TypeAdapterConfig<Person, FlatDto>.NewConfig()
    .Map(dest => dest.AddressCity, src => src.Address.City);
```

### Forge

```csharp
[Forge]
public static partial class MyForges
{
    [ForgeMethod(AllowFlattening = true)]
    public static partial FlatDto ToDto(Source source);
}
// Generates: __result.AddressCity = source.Address?.City;
```

Automatic name-based discovery, arbitrary depth (up to 10 levels), automatic null-conditional operators.

## 11. Type Converters

### Mapster

```csharp
TypeAdapterConfig.GlobalSettings.Default
    .AddDestinationTransform((DateTime dt) => dt.ToString("yyyy-MM-dd"));
```

### Forge

```csharp
[Forge]
public static partial class MyForges
{
    public static partial Dest ToDto(Source source);

    [ForgeConverter]
    public static string DateToString(DateTime value) => value.ToString("yyyy-MM-dd");
}
// Generates: __result.Birthday = DateToString(source.Birthday);
```

## 12. Before/After Hooks

### Mapster

```csharp
TypeAdapterConfig<Person, PersonDto>.NewConfig()
    .BeforeMapping((src, dest) => { /* ... */ })
    .AfterMapping((src, dest) => { /* ... */ });
```

### Forge

```csharp
[Forge]
public static partial class PersonForges
{
    public static partial PersonDto ToDto(Person source);

    static partial void OnBeforeToDto(Person source) { /* ... */ }
    static partial void OnAfterToDto(Person source, PersonDto result) { /* ... */ }
}
```

Compile-time checked — if you misspell the method name, you get a build error.

## 13. Conditional Mapping

### Mapster

```csharp
TypeAdapterConfig<Source, Dest>.NewConfig()
    .Map(dest => dest.Name, src => src.Name, src => src.Name != null);
```

### Forge

```csharp
// Null-check
[ForgeMethod(IgnoreIfNull = ForgePolicy.True)]
public static partial void Update(Source source, Dest existing);

// Default-check
public class Dest
{
    [ForgeMap("Age", IgnoreIfDefault = true)]
    public int Age { get; set; }
}

// Custom condition
public class Dest
{
    [ForgeMap("Salary", Condition = nameof(PersonForges.CanUpdate))]
    public decimal? Salary { get; set; }
}
```

## 14. EF Core / IQueryable Projections

### Mapster

```csharp
var dtos = await dbContext.People
    .ProjectToType<PersonDto>()
    .ToListAsync();
```

### Forge

```csharp
[Forge]
public static partial class PersonForges
{
    [ForgeMethod(GenerateExpression = true)]
    public static partial PersonDto ToDto(Person source);
}

var dtos = await dbContext.People
    .Select(PersonForges.ToDtoExpression)
    .ToListAsync();
```

**Key difference:** Forge generates the expression at compile time — no runtime expression building.

## 15. Nullable Handling

### Mapster

Mapster handles nullable conversions automatically at runtime.

### Forge

Automatic handling plus `DefaultValue` fallbacks:

```csharp
public class Source
{
    [ForgeMap("Age", DefaultValue = 0)]
    public int? Age { get; set; }
}
// Generates: __result.Age = source.Age ?? 0;
```

## 16. Strict Mapping

### Mapster

Mapster doesn't have built-in strict mapping / drift detection.

### Forge

```csharp
[ForgeMethod(StrictMapping = true)]
public static partial PersonDto ToDto(Person source);
// FKF110 error for unmapped destination members
// FKF111 error for unused source members
```

## 17. Dictionary Mapping

### Mapster

```csharp
var dict = person.Adapt<Dictionary<string, object>>();
var person = dict.Adapt<Person>();
```

### Forge

```csharp
[Forge]
public static partial class ConfigForges
{
    [ForgeMethod]
    [ForgeDictionary(KeyCasing = KeyCasingPolicy.CamelCase)]
    public static partial Person FromDict(Dictionary<string, object> dict);

    [ForgeMethod]
    [ForgeDictionary(NullValue = NullValuePolicy.Skip)]
    public static partial Dictionary<string, object> ToDict(Person person);
}
```

**Forge's advantage:** Fine-grained control over key casing, missing keys, and null values — all at compile time.

## 18. Polymorphic Mapping

### Mapster

Mapster doesn't have built-in polymorphic dispatch.

### Forge

```csharp
[Forge]
public static partial class AnimalForges
{
    public static partial DogDto MapDog(Dog source);
    public static partial CatDto MapCat(Cat source);

    [ForgePolymorphic(typeof(Dog), nameof(MapDog))]
    [ForgePolymorphic(typeof(Cat), nameof(MapCat))]
    public static partial AnimalDto MapAny(Animal source);
}
```

## Migration Checklist

- [ ] **Install packages**: Add `FreakyKit.Forge.Generator` and `FreakyKit.Forge.Analyzers`
- [ ] **Remove Mapster**: Uninstall `Mapster`, `Mapster.Core`, and `Mapster.Tool`
- [ ] **Remove DI registration**: Delete `TypeAdapterConfig` and `ServiceMapper` registrations
- [ ] **Remove `.Adapt<T>()` calls**: Replace with static forge calls or extension methods
- [ ] **Convert fluent config to attributes**: `.Map()` → `[ForgeMap]`, `.Ignore()` → `[ForgeIgnore]`
- [ ] **Create forge classes**: Each configuration group becomes a `[Forge]` static partial class
- [ ] **Convert transforms to converters**: `.AddDestinationTransform()` → `[ForgeConverter]` methods
- [ ] **Convert hooks**: `.BeforeMapping()`/`.AfterMapping()` → `OnBefore{Method}`/`OnAfter{Method}` partials
- [ ] **Enable nested forging**: Add `AllowNestedForging = true` where types differ
- [ ] **Enable flattening**: Add `AllowFlattening = true` where name-based flattening is used
- [ ] **Convert projections**: `.ProjectToType<T>()` → `GenerateExpression = true` + `.Select(Expression)`
- [ ] **Build and fix diagnostics**: The compiler guides you

### Quick Reference: Mapster → Forge

| Mapster | Forge |
|---------|-------|
| `source.Adapt<Dest>()` | `ForgeClass.ToDto(source)` or `source.ToDto()` |
| `TypeAdapterConfig<S, D>.NewConfig()` | `[Forge]` static partial class + method signature |
| `.Map(d => d.X, s => s.Y)` | `[ForgeMap("Y")]` on destination property `X` |
| `.Ignore(d => d.X)` | `[ForgeIgnore]` on property |
| `[AdaptMember("name")]` | `[ForgeMap("name")]` |
| `[AdaptIgnore]` | `[ForgeIgnore]` |
| `.MapToConstructor(true)` | Automatic |
| `.BeforeMapping()`/`.AfterMapping()` | `OnBefore{Method}`/`OnAfter{Method}` partial methods |
| `.AddDestinationTransform()` | `[ForgeConverter]` static method |
| `source.Adapt(existing)` | Void method with 2 params |
| `.ProjectToType<T>()` | `GenerateExpression = true` + `.Select(Expression)` |
